# TaskFlow – Mobile App UI/UX Design

## About the Project
TaskFlow is a mobile app wireframe designed using Figma to help users organize daily tasks, manage deadlines, and track their progress.

## Project Objective
To create a simple, user-friendly interface that makes task management easier.

## Tools Used
- Figma
- UI/UX Design
- Wireframing
- Prototyping

## Screens Designed
1. Welcome Screen
2. Home Screen
3. Add New Task
4. Task Details
5. Profile & Settings

## Key Features
- Simple and user-friendly interface
- Organized task management
- Easy navigation
- Clear task details
